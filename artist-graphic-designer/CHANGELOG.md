# Changelog

## 0.2.0

- تحويل المهارة من ملف واحد كبير إلى ملف توجيهي مع مراجع متخصصة قابلة للتحميل التدريجي.
- تقوية منهجية العصف الذهني وتطوير أفكار المستخدم بدل نسخها أو تجاهلها.
- إضافة بوابة واضحة للفصل بين Graphic Design وUI/UX.
- إضافة سجل قرارات تصميم قابل للمراجعة دون كشف التفكير الداخلي الخاص.
- إضافة بروتوكولات مقاومة AI slop، وتحليل المراجع، والنقد، والتسليم.
- إضافة 13 مرجعًا متخصصًا قابلًا للتحميل حسب نوع المهمة.
- إضافة 8 سيناريوهات تقييم وملف إرشادات لتشغيلها ومقارنة النتائج.
- إضافة أداة تحقق بنيوية للحزمة وتوثيق طريقة استخدامها.

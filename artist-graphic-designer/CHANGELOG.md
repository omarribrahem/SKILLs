# Changelog

## 0.4.0

- دمج Marketing-led Creative Design OS مع المهارة الفنية الأصلية دون استبدال فلسفتها.
- إضافة منهجية A–M تربط فهم المهمة والبيزنس والجمهور والبحث والـBrief والاستراتيجية الإبداعية والـConcept والتوجيه الفني والتكوين والإنتاج والمراجعة والتسليم والتعلم.
- إضافة فصل بين Business Goal وMarketing Objective وCommunication Objective.
- إضافة Consumer Insight وMessage / Proof / CTA وربط الهدف بالـKPI.
- إضافة مسارات اختيار الإنتاج AI-first وAdobe-first وHybrid وManual وPhotography.
- إضافة دليل AI + Adobe يوضح توزيع الأدوار وحماية الشعارات والعبوات والأصول الدقيقة.
- إضافة Phase Self-Questions لتدريب المصمم على التفكير مرحلة بمرحلة.
- إضافة قوالب Creative Brief وPerformance Learning.
- إضافة تعليمات جاهزة لاستخدام المهارة داخل ChatGPT Project.
- توسيع اختبارات المهارة لتشمل التسويق والـInsight والإنتاج الهجين والتعلم والتعديلات السريعة.
- الحفاظ على قواعد الأصالة ومقاومة AI slop وسلامة النص العربي والمكونات المستقلة.

## 0.3.0

- إضافة component-integrity.md لضبط سلامة العناصر المستقلة مثل Labels وDividers والأيقونات.
- إضافة Exact Copy Source لمنع إعادة كتابة النصوص أو ترك النص العربي الدقيق لمولّد الصور.
- إضافة فصل واضح بين الصورة المولدة وطبقات النصوص والشعارات والفواصل الدقيقة.
- تقوية فحص العربية وRTL واتصال الحروف والنقاط والهمزات والمحاذاة.
- توسيع النقد ليشمل فحص المكونات الدقيقة قبل اعتماد التصميم.
- إضافة حالتي تقييم جديدتين لدقة النص العربي وإصلاح شرائط المكونات المولدة.
- تحديث دليل التقييم وهيكل الحزمة.

## 0.2.0

- تحويل المهارة من ملف واحد كبير إلى ملف توجيهي مع مراجع متخصصة قابلة للتحميل التدريجي.
- تقوية منهجية العصف الذهني وتطوير أفكار المستخدم بدل نسخها أو تجاهلها.
- إضافة بوابة واضحة للفصل بين Graphic Design وUI/UX.
- إضافة سجل قرارات تصميم قابل للمراجعة دون كشف التفكير الداخلي الخاص.
- إضافة بروتوكولات مقاومة AI slop، وتحليل المراجع، والنقد، والتسليم.
- إضافة 13 مرجعًا متخصصًا قابلة للتحميل حسب نوع المهمة.
- إضافة سيناريوهات تقييم وملف إرشادات لتشغيلها ومقارنة النتائج.
- إضافة أداة تحقق بنيوية للحزمة وتوثيق طريقة استخدامها.
